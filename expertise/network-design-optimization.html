Expertise 04 · Network Design Optimization

Pricing resilience into the network, not bolting it on after.

Facility, sourcing, and capacity decisions typically get optimized on landed cost alone, against a single deterministic forecast. Resilience shows up afterward, as a qualitative overlay — which means it loses to a cheaper number every time it's asked to compete on merit.

The fix isn't a qualitative resilience checklist bolted onto a cost-optimized plan after the fact — it's making resilience and flexibility part of the same optimization that picks facilities, capacities, and sourcing lanes in the first place, priced in dollars the same way cost already is. Two computational techniques do that work. Stochastic and mixed-integer programming solves the network design problem jointly across many demand and disruption scenarios at once, instead of once against a single forecast, so the chosen configuration is good across the scenario set, not just optimal for the one future that happened to get modeled.

Monte Carlo simulation answers a related but different question about a network design that's already on the table: given how often things actually fail (a lane's own disruption rate, a node's own outage rate), what does the distribution of outcomes look like — the median case, the bad-but-plausible tail, the genuinely catastrophic one — rather than a single expected-value number that hides how fat that tail actually is.

Run together, the two techniques cover both ends of the same problem: stochastic programming designs the network with the scenario spread already priced in; Monte Carlo stress-tests whatever network you land on (or already have) to show what that spread actually looks like once it's built, plus a targeted search for the specific single point of failure or worst plausible combination of failures that would hurt it the most.

Reference
Core question
What network configuration is actually best once the cost of things going wrong is priced in, not just the cost when everything goes right?
Business value
A network design with flexibility and resilience priced into the decision, not argued for afterward — plus a concrete answer for how that specific network performs under realistic failure rates, not just its best-case number.
Core method
Mixed-integer and stochastic programming for the design decision itself; Monte Carlo sampling and targeted worst-case search to characterize how a given design actually performs under realistic failure rates.
Where it shows up here
The Network Stress Test sandbox runs a real min-cost-flow model of a production/warehouse/consumer network against an N-1 contingency scan (which single node or lane hurts the most), Monte Carlo random-failure sampling (the realistic distribution of outcomes), and a greedy adversarial search for the worst combination of simultaneous failures.
