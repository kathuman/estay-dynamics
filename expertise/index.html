Areas of expertise

Four business problems, priced properly.

Every engagement starts from a business situation — a problem that keeps recurring, a risk nobody can quite put a number on, a network decision under real uncertainty — not from a modeling technique. These are the four situations I work on most, each described here in plain terms first, with the formal method behind it available if you want it.

01 / Feedback & structure

System Dynamics

For the problem that keeps resurfacing no matter which process or person gets replaced, because the fix never touched the structure producing it. The output is a diagnosis that holds, and a team that actually agrees on it.

Read more → 02 / Propagation, not probability

Systemic Risk Analysis

For the risk that's rated "medium, contained" right up until it isn't, because a static score can't say whether your network absorbs a shock or amplifies it. The output is a number for how far a disruption actually travels.

Read more → 03 / The value of waiting

Real Options

For the network decision you're being asked to lock in today under uncertainty that won't resolve for years. The output is a price on the alternative — wait, stage, or walk away — so flexibility competes on equal footing with commitment.

Read more → 04 / Pricing resilience in

Network Design Optimization

For the facility, sourcing, or capacity decision optimized on landed cost alone, with resilience bolted on after as a qualitative overlay that never wins. The output is a network priced with the cost of failure already built in.
