The attack-defence loop, live.

A five-stock system dynamics model of a cyber-physical ship ballast control system under attack — attacker foothold, perceived compromise, response capacity, ballast deviation, and containment effectiveness. Move the sliders and watch the network's own detection delay decide whether the attack is contained or the ballast system loses stability.

Fig. 01 — Model structure (5 stocks, 3 feedback loops)

Amber marks the reinforcing loop (R1) — attacker propagation left unchecked. Cyan marks the response loop (B1) — perception, delayed by τ_d, mobilises response that contains the attacker. Purple marks the adaptation loop (B3) — sustained response gradually raises containment effectiveness. Ballast deviation (B, red) is the physical consequence: it has no feedback of its own, which is exactly why it can only be managed indirectly, through A and R.
